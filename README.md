## 目录

### 算法

- 算法基础：算法定义、复杂度、渐进记号
- 排序：选择、冒泡、插入、计数、桶、希尔、归并、快速、基数排序
- 前缀和与差分：一维、二维、高维形式及常见模型
- 离散化：有序映射、线段/矩形并
- 二分：二分查找、二分答案、分数规划
- 双指针：区间单调性与滑动窗口
- 贪心：贪心证明、简单策略、相邻交换、反悔贪心
- 动态规划：记忆化搜索、背包、序列 DP、区间 DP

### 数据结构

- 基础结构：数组、链表、栈、队列、集合、映射、堆
- ST 表：RMQ、可重复贡献问题、静态查询
- 线段树：懒惰标记、复合标记、最大子段和、动态开点、标记永久化
- 权值线段树与线段树常见技巧
- 树状数组：单点修改、区间查询、差分维护、树状数组上二分

### 图论

- 图基础：图的定义、路径与连通、子图、稀疏图与稠密图
- 遍历与结构：DFS/BFS、二分图、拓扑排序、DAG
- 最短路：Dijkstra、Bellman-Ford/SPFA、Floyd、Johnson
- 树基础：树的定义、重心、DFS 序、括号序、欧拉序
- 树上算法：LCA、直径、中心、最小生成树

### 字符串

- 字符串基本概念：字符集、子串、子序列、字典序
- 字符串哈希：单哈希、双哈希、子串哈希、二分哈希
- 字典树：Trie、01-Trie、前缀统计与按位贪心
- KMP（预留章节）

### 博弈论

- 博弈论简介：必胜/必败局面、Bash 博弈
- 公平组合游戏：Nim、K-Nim、有向图游戏、SG 函数
- 反常博弈：Anti-Bash、Anti-Nim、Anti-SG
- 其他博弈模型：非对称操作、平局、策略优化

### 真题与杂题

- 科大国创杯 2025 初中组题解
- Ad-hoc 乱讲：ICPC/CCPC 区域赛与 EC Final 题目选讲

## 使用

各目录下的 PDF 是最终课件版本。Typst 源文件、模板和图片素材仅用于本地维护与编译，不作为公开仓库内容上传。
