# 树上计数、路径与回溯

[返回总目录](../../README.md)

## 通用思路

树中两点间路径唯一。统计某类短路径时，可枚举唯一中点或 LCA，避免直接枚举点对。对子树可聚合的量，用后序遍历；根路径上的量，用 DFS 维护进入和离开的状态。

树上的栈与线性串的栈不同：访问完一个子树后必须恢复原状态，才能进入兄弟子树。推荐显式写“进入点做什么、离开点撤销什么”，而不是在递归函数末尾凭印象补操作。

## 三种降维

- 距离为 2 的两点 → 枚举唯一中点 → 邻居权值和、平方和、前两大。
- 根路径括号统计 → 以当前点结尾的方案数 → 根路径累计。
- 任意树路径 → LCA 拆上下行 → 深度等式 → 同键事件与子树差分。

复杂路径题先枚举路径取小规模分，再考虑离线。LCA 本身只负责找分叉点，不会自动把逐路径访问变成高效算法。

## 常见错误

- 上下行都包含 LCA，重复统计一次。
- 根深度取 0 和取 1 的公式混用。
- DFS 的全局桶混入已经访问的兄弟子树，忘记记录进入前快照。
- 深链导致递归爆栈；应支持显式栈的进入/离开事件。
- 路径个数和答案乘积超过 32 位。

## 练习顺序

联合权值 → 括号树的链分支 → 一般括号树 → 天天爱跑步的逐路径暴力、$w=0$、全根起点。最后才阅读任意路径的桶统计。
