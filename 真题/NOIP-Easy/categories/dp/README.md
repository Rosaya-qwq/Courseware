# 动态规划与状态设计

[返回总目录](../../README.md)

## 通用思路

状态要保留所有会影响未来的信息，并删掉能由别的状态量唯一算出的信息。写代码前先完整写出：状态含义、初值、合法下标、转移、处理顺序、答案位置与复杂度。

从暴力搜索出发，两个搜索节点若剩余问题相同，就合并为状态。计数题还需规定唯一的拆分方式，避免同一个对象经不同转移重复计算。优化时先保证朴素 DP 正确，再找转移中可维护的统计量或被支配的候选。

## 本题单里的状态来源

| 特征 | 适合保留的信息 | 典型题 |
| --- | --- | --- |
| 同类资源互相等价 | 每类已用数量 | 乌龟棋 |
| 是否仍在同一连续段 | 当前字符选中状态、段数 | 子串 |
| 无限重复取同一物品 | 当前可达金额，正序更新 | 货币系统 |
| 选了哪些顶点 | 顶点子集与层数 | 宝藏 |
| 唯一递归文法 | 区间、外层类型 | 括号序列 |
| 按位相加 | 已用位置、低位 1 数、进位 | 数列 |

## 部分分的取法

先把状态范围收窄到原题的小规模或特殊条件，再减维，例如 $k=1$、$k=m$、小 $m$。不要只说“写暴力 DP”：必须知道哪些状态、转移和最终答案。计数 DP 中排列数、取模和空方案处理都属于正确性的一部分。

## 常见错误

- 最小值 DP 把不可达初始化为 0。
- 应来自上一层的值被本层覆盖，造成重复选择。
- 把不同分段方案合并，或把同一对象的多种拆法重复计数。
- 只看转移，不计算状态数乘转移数。

## 练习顺序

乌龟棋 → 货币系统 → 子串的 $k=1,k=m$ → 子串完整 DP。括号序列、数列、宝藏、划分和填数游戏本周以部分分为主；Emiya 家今天的饭是较难 T1，适合集中讲解。
