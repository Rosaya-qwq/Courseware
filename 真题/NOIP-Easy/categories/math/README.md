# 数学、位运算与组合计数

[返回总目录](../../README.md)

## 通用思路

先确定计数对象与必要条件。一次独立选择用乘法原理，多类互斥对象用加法；直接数合法情况困难时，尝试“总数减不合法”。若多个违规事件互斥，可直接逐个扣除，否则需要容斥或重新分类。

大指数用快速幂，大范围整除条件考虑筛法。涉及二进制时，明确是按位或、异或、位数、奇偶还是进位，不能只凭题目中出现 2 的幂就套同一公式。

## 常用工具

| 工具 | 使用条件与提醒 |
| --- | --- |
| Pascal 组合数 | 任意正模数都适用；滚动时倒序 |
| 阶乘逆元 | 模数为质数且阶乘不为 0；不能无条件使用 |
| 扩展欧几里得 | 求整数线性组合，逆元要求互质 |
| 按位自由选择 | 每位独立；先检查跨位规则是否存在 |
| 筛倍数 | 一个基础坏数会让全部倍数变坏 |
| 分段乘法原理 | 各段参数独立，共享端点已经固定 |

## 证明与实现

写公式时同时写边界：空方案算不算、严格还是非严格、同位置约束是否冲突、幂指数是否可能为 0。大数先估计中间结果，再选类型。无符号 64 位仍装不下 $2^{64}$，也不允许移位 64。

“找到了几项规律”可以提出猜想，不能替代证明；至少保留独立暴力核对工具。像清仓甩卖这样的题，应先数贪心失败的唯一结构，再套组合恒等式，不能从公式倒猜计数意义。
