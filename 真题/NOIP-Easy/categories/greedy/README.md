# 贪心、排序与交换论证

[返回总目录](../../README.md)

## 通用思路

先说清每一步选择什么，再说明为什么存在一个最优解也这么选。常见证明有三种：

- **相邻交换**：比较 $i,j$ 和 $j,i$ 两种顺序，找出只与两件物品有关的排序条件。
- **局部替换**：把某个最优解中的选择换成当前贪心选择，验证仍合法且目标不变差。
- **下界与构造**：先证明至少需要多少次操作，再给出恰好达到下界的方案。

另一类从无约束上界出发：每人先取最大收益，再用最小损失修正违反容量的部分。若决策同时有“无限重复”和“每种有限次”两部分，可先拆开，再枚举有限部分的数量。

## 常见模型

相邻增量只在上升处新开操作；最长摆动子序列只保留峰谷；一维区间至少选一点时按右端点排序；价值平方和配对可先展开，再用同序配对；一次模拟回答所有容量时，需要证明前 $k$ 个资源与有限容量过程一致。

## 常见错误

- 只写“显然按某键排序”，没有交换代价。
- 对排序比较器用减法，导致溢出或不满足严格弱序。
- 把对正数成立的性质扩展到负数、零，或忽略容量奇偶。
- 看起来接近最优就当正确，没用小规模穷举寻找反例。
