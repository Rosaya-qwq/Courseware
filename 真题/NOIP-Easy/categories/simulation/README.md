# 模拟与规则实现

[返回总目录](../../README.md)

## 通用思路

先定义状态，再列出一次操作会读取和修改的量。循环移动、大小写、栈帧等规则尽量转成小表或统一公式，减少互相重叠的分支。每一步都应保持清楚的不变量，例如“队列成员与存在标记一致”“辅助栈保持为空”。

遇到整体相同变化，优先寻找统一增量：每次给全部元素加一个数，可把元素存为“实际值减累计增量”，只更新一个全局变量。操作次数极大但状态有周期时，用整周期跳跃，再处理短余段。

## 实现顺序

1. 用自然语言写出初态、一次操作、终态及输出。
2. 将边界列成表，确认每个输入只进入一个分支。
3. 先写最直接的小规模模拟，再替换耗时的一层。
4. 用同一个小例子逐步打印状态，对照手算；通过后删除调试输出。

## 常见错误

- 修改完状态后才读取本应来自旧状态的信息。
- 环形下标负数取模、从 0 与从 1 编号混用。
- 以为“本轮不执行”就不需要检查其中语句语法。
- 多测中保留队列、计数器或栈里的旧数据。
- 把很重的模拟 T1 误认为必须十分钟写完，挤占后面题目的保底时间。

## 练习顺序

机器翻译 → Vigenère 密码 → 玩具谜题 → 神奇的幻方 → 时间复杂度。蚯蚓先练堆与统一增量，儒略日作为长模拟选做。
