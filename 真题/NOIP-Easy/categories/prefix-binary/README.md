# 前缀统计、差分与二分

[返回总目录](../../README.md)

## 通用思路

区间信息若能由两个前缀之差得到，就先预处理前缀；多次对连续区间加相同量，可以先在两个端点写差分，再一次还原。枚举端点时若有效范围只会扩张，用不回退的指针维护累计信息。

二分答案必须先有一个正确的 `check(x)`，并证明它的真假随着 $x$ 只变化一次。检查函数不需要直接算最优值，只要回答“这个目标是否能达到”。常见形式是“至少距离 $d$”“前 $k$ 个订单能否满足”“阈值 $W$ 下贡献是否超过目标”。

静态区间多次求极值，用 ST 表；动态修改才需要相应动态结构。先从朴素扫描提取查询真正需要的统计量，再选择数据结构，避免拿到区间题就套线段树。

## 二分边界

明确找第一个真、最后一个真还是最接近目标。最小化绝对误差时，原函数可能单调，但绝对误差不单调；应找跨过目标的两个位置分别比较。每次检查若重用差分数组，必须清空。

## 常见错误

- 把闭区间 $[l,r]$ 写成在 $r$ 处撤销差分，而不是 $r+1$。
- 忽略检验值的乘积和累加溢出。
- 二分可以结束，却没检查答案是否在搜索范围中。
- 枚举左右端点时把当前右端点也纳入左端点集合。

## 练习顺序

选择客栈 → 借教室 → 跳石头 → 聪明的质监员 → 策略游戏。种花用逐列累计消去一层枚举，适合作为统计专题提高题。
