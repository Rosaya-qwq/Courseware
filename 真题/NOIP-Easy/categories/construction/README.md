# 构造与不变量

[返回总目录](../../README.md)

## 通用思路

构造题需要输出每一步合法操作。先设计容易维护的局面，说明初态满足、一次操作后仍满足、最后能达到目标，这三个步骤组成不变量证明。

一个很有用的结构是始终保留一个空辅助容器，将其余容器容量限制在很小的范围；正常情况用统一操作，只有空间被占满时才单独讨论。若在线决策难以判断，可以离线预看第一个会破坏当前结构的位置，但必须证明前瞻扫描的总成本。

## 部分分路线

先利用 $k=2n-2$ 的固定配色，让每个普通栈只负责两种颜色；这时每次匹配都能直接在栈顶或借空栈从栈底完成。一般 $k=2n-1$ 的前瞻构造细节明显更多，不应挤掉已经能确定拿到的分支。

小规模构造可搜索完整状态，记忆化已经失败的局面。可交换的空容器编号往往可以规范化，但输出时仍需还原合法的真实编号。

## 必须回放检查

本地实现一个只根据题意执行操作的模拟器，检查：牌是否按顺序取出、栈编号是否合法、栈底消除是否符合条件、最终是否全部为空、操作次数是否超限。构造程序与回放器的逻辑应独立，不能用构造内部的“我认为已经消掉”代替实际回放。

## 常见错误

- 临时占用辅助栈后，没有在继续一般处理前恢复不变量。
- 只更新颜色位置，漏更新空位集合或辅助栈编号。
- 找到一串操作，却没有证明次数与运行时间。

## 练习顺序

本周只把喵了个喵的 $k=2n-2$ 分支列为必写，先写回放器再扩展搜索档；满分构造作为阅读选做。
