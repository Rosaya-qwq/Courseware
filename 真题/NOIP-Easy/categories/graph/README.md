# 图的建模、遍历与连通

[返回总目录](../../README.md)

## 通用思路

先判断边有向还是无向、是否有环、边权是否相同，再选图算法。无权最短路用 BFS，DAG 依赖传播用拓扑排序，无向连通用并查集，连通所需最小总边权用 MST。

若题目关心“哪些点能到达终点”，从终点在反图遍历一次。若图每点恰好有一个后继，优先考虑函数图：剥离入度为 0 的树枝后，剩余为若干环。若只比树多一条边，则只需枚举环上删哪条边。

## 从复杂条件到标准算法

将“允许走的点”预处理，再求路；将“孔洞相交”转成边，再判连通；将程序执行后的变量来源转成带取反位的等式图，再分析分量。把建模与图算法分开，便于各自验证。

对很多次相近的 MST，要先考虑候选边压缩。保留原图一棵 MST 后增加新边，不会丢失最优生成树的价值；证明用路径替换，不能声称所有非树边从此绝无可能属于任意 MST。

## 常见错误

- 有向图可达性误用无向并查集。
- 把最短路长度与转车次数、点数混为一谈。
- 拓扑排序只放有贡献的点，漏掉无贡献前驱造成的依赖。
- 构造图时只处理连通性，忘记每条边附带的符号或数值关系。
- 分数传播使用浮点数，无法还原题目要求的最简分数。

## 练习顺序

信息传递 → 寻找道路 → 奶酪 → 旅行的树分支 → 排水系统。三值逻辑先练 U/复制分支，道路修复先练小子集加 Kruskal，假期计划练固定中间点与候选压缩。
