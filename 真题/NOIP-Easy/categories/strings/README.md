# 字符串、奇偶与状态编号

[返回总目录](../../README.md)

## 通用思路

先区分子串（连续）和子序列（允许跳过）。字符串判断若能压缩成统计量，应证明这些量足够；字符频次、奇偶集合、最小最大字母、约简后的栈，各自适用于不同约束。

对周期前缀用 Z 函数或等价精确匹配，不必在每个块长下逐字符重比。判断两个状态是否相等时，可用 Trie 的结点编号获得精确状态，也可用哈希换取简洁，但要说明碰撞可能。

## 本题单的三个转化

- 词典：最优重排方向分别升序、降序；等长保证首字符已决定能否严格更小。
- 消消乐：任意消除 → 唯一约简栈 → 前缀状态相等的数对计数。
- 字符串匹配：块的周期检查与切点奇偶条件分开；Z 函数负责前者，小值域前缀计数负责后者。

## 常见错误

- 认为每种字母数量为偶数就一定可相邻消空，`abab` 是反例。
- 多个字符串比较只保留首字符，却没证明长度及剩余字符的约束。
- 匹配题漏掉 $A,B,C$ 都必须非空，或把 $t=1$ 漏掉。
- 前缀相同状态计数时先加频次再算贡献，把空子串算进去。
- 一律使用大字母表 Trie 数组，忽视内存规模。

## 练习顺序

词典 → 消消乐的二次方栈模拟 → 精确状态编号。字符串匹配本周先做小范围枚举和单字符特例，Z 函数优化留作提高。
