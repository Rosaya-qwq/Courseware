# 聪明的质监员

2011 NOIP 提高组 · Day 2 · T2 · 必练 · 建议独立尝试 50 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/prefix-binary/README.md)

## 题意

给定阈值 $W$，每个区间的贡献为其中 $w_i\ge W$ 的矿石个数乘这些矿石的价值和。所有区间贡献之和为 $Y(W)$，最小化 $|Y(W)-S|$。

## 关键部分分

- $n,m\le10$：只枚举不同重量和“全部不选”的阈值，每次扫描各区间，$O(n^2m)$。
- $n,m\le500$：每个阈值用两个前缀和计算所有区间，$O(n(n+m))$。若继续枚举所有阈值，会卡在较大范围；下一步应消去阈值这一层。

## 做法

对固定 $W$，构造计数前缀和 $C$ 和价值前缀和 $V$，区间 $[l,r]$ 的贡献为 $(C_r-C_{l-1})(V_r-V_{l-1})$。一次求值 $O(n+m)$。

所有价值为正，$W$ 增大时每个区间的计数和价值都不增，因此 $Y(W)$ 单调不增。二分找第一个 $Y(W)\le S$ 的阈值，比较该点及前一个阈值的绝对误差。搜索范围可取 $[0,\max w_i+1]$。

## 实现与复杂度

时间 $O((n+m)\log\max w)$，空间 $O(n+m)$。原题最坏的 $Y$ 可能超出 64 位，乘积和累加用 `__int128`；最终最优误差可安全转回题目输出类型。不要只比较二分结束点，也不要二分绝对值函数。

## 训练目标

完整写出 `calc(W)`，说明单调性，主动处理阶梯函数两侧。
