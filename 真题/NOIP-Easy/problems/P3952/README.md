# 时间复杂度

2017 NOIP 提高组 · Day 1 · T2 · 必练 · 建议独立尝试 60 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/simulation/README.md)

## 题意

给定由 `F i x y`、`E` 组成的伪程序，判断是否语法错误；若无错误，判断其复杂度是否与声明的 $O(1)$ 或 $O(n^w)$ 一致。

## 关键部分分

- 先实现语法检查：用栈匹配 `F/E`，用集合记录正在使用的循环变量。重复使用活动变量、空栈遇 `E`、结束栈不空均为 `ERR`。即使循环不执行，语法仍须检查。
- 只有常数边界时：语法正确即为 $O(1)$；此分支仅覆盖该限制。
- 无法执行的循环会屏蔽其内部的复杂度贡献，补上这个状态后就可以实现完整算法，不必为每个特殊点写独立程序。

## 做法

将边界解析为“常数”或符号 $n$。每个 `F` 保存变量名、此层是否导致不执行、是否增加一次 $n$ 的指数。

| 下界 | 上界 | 结果 |
| --- | --- | --- |
| 常数 $x$ | 常数 $y$ | $x\le y$ 则常数次，否则不执行 |
| 常数 | $n$ | 执行 $\Theta(n)$ 次 |
| $n$ | 常数 | 不执行 |
| $n$ | $n$ | 一次 |

维护不执行层数 `dead` 和当前有效指数 `cur`。若进入前 `dead=0` 且本层是常数到 $n$，令 `cur++`；只有在可执行区域更新最大指数。退栈按该帧实际贡献撤销。最大指数对应顺序语句取最大，嵌套循环取指数相加。

## 实现与复杂度

时间 $O(L)$，空间 $O(L)$。字符串解析支持多位常数和多位指数；$O(n^0)$ 与 $O(1)$ 同阶。即使已发现错误，仍读完本组全部 $L$ 行，不能污染下一组输入。

## 训练目标

按“语法 → 边界四分类 → 屏蔽不执行区域”顺序实现，至少各造一组测试。
