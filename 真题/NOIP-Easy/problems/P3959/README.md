# 宝藏

2017 NOIP 提高组 · Day 2 · T2 · 拓展 · 建议独立尝试 80 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/dp/README.md)

## 题意

选一个免费开通的根，以生成树方式依次开通其余点。边长乘其父亲到根路径上的点数就是开通代价，求最小总代价，$n\le12$。

## 关键部分分

- 原图是一棵树：枚举根，DFS 得深度，代价为 $\sum_{(p,u)}dep_p\,w_{pu}$，根深度取 1。时间 $O(n^2)$，覆盖输入为树的一档。
- $n\le8$：枚举根和一个顶点加入顺序，每次为新点枚举已加入的父亲会非常大；更稳妥是直接实现下面的层次状压 DP，将 $n$ 限到 8，保留正确状态。
- 边权全部相同：对每个根 BFS，按最小深度连入，最小化各非根点的父深度之和，$O(n(n+m))$。这是原题前 40% 的共同限制；必须包括非连通判断。

## 做法

令根深度为 0，已建到第 $d$ 层的顶点集合为 $S$。$f[d][S]$ 表示构造一棵覆盖 $S$、高度至多 $d$ 的根树的最小代价；初始每个单点 $f[0][\{r\}]=0$。

对不在 $S$ 的点 $v$，预处理 $c(S,v)=\min_{u\in S}w_{uv}$。选非空新集合 $T\subseteq V\setminus S$，每个新点独立连到 $S$ 中最便宜的点：

$$f[d+1][S\cup T]\gets\min\left(f[d+1][S\cup T],f[d][S]+(d+1)\sum_{v\in T}c(S,v)\right).$$

不存在连接边的 $T$ 不转移。允许父亲位于比 $d$ 更浅的层会暂时高估该边，但不会低估可实现方案；任何最优树按真实深度分层也会被枚举，故取所有 $d$ 的满集最小值恰为最优。

## 实现与复杂度

预处理 $c(S,v)$ 用去掉一个二进制位的递推，$O(n2^n)$；枚举互斥 $S,T$ 总数为 $O(3^n)$，各 $T$ 费用用子集和递推可做到每转移 $O(1)$，总时间 $O(n3^n+n^22^n)$，空间 $O(n2^n)$。重边取最小权，不可达取无穷。

## 训练目标

本周先完成树与等权图两档；满分重点理解“枚举一层的点集”，不要套普通 MST。
