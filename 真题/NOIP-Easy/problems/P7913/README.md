# 廊桥分配

2021 CSP-S · T1 · 提高 · 建议独立尝试 65 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/greedy/README.md)

## 题意

将 $n$ 个廊桥分给国内、国际航班，两类分别按到达顺序占用空闲廊桥，离开后释放，最大化获得廊桥的总航班数。

## 做法

对每类独立模拟拥有无限编号廊桥时的分配：按到达时间排序，忙碌堆按离开时间释放廊桥，空闲堆总取最小编号，记录每个编号接待了多少班。

给该类 $k$ 个廊桥时，接待数恰为上述编号 $1\ldots k$ 的次数之和。原因是：只要有限模拟存在空闲廊桥，无限模拟也一定选择最小的前 $k$ 个空闲编号之一；无限模拟给编号大于 $k$ 的航班不会占据前 $k$ 个廊桥，也就不会影响后面的有限模拟。

得到两类前缀和 $A_k,B_k$，枚举 $k=0\ldots n$，答案 $\max(A_k+B_{n-k})$。

## 实现与复杂度

时间 $O((m_1+m_2)\log(m_1+m_2)+n)$，空间 $O(m_1+m_2+n)$。原题时间互不相同，按“离开后才可重用”释放；扩展到同一时刻时要先明确是否允许衔接。两类分别重新初始化堆，分配 0 个廊桥的前缀和为 0。

## 训练目标

先写单次给定 $k$ 的堆模拟，再理解一次无限模拟为何能回答所有 $k$。
