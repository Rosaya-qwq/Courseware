# 乌龟棋

2010 NOIP 提高组 · T2 · 必练 · 建议独立尝试 45 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/dp/README.md)

## 题意

棋盘每格有分值，四种卡片分别前进 1、2、3、4 格，每张恰好使用一次，最大化经过格子的分值和。

## 关键部分分

- 卡片很少时，搜索每一步使用哪一种剩余卡片，计算位置和得分。同种卡片只按种类分支，避免重复排列；粗上界 $O(4^M)$。
- 只有一种卡片时，路径唯一，顺序累加即可。这是帮助理解状态的特例，不承诺独立计分。
- 从上述搜索记忆化：未来只由四类卡片已经用了多少张决定，直接得到满分状态。

## 做法

设四种卡片数量为 $c_1,c_2,c_3,c_4$。$f[a][b][c][d]$ 为已使用这些数量后的最大分值，当前位置唯一为

$$p=1+a+2b+3c+4d.$$

初始化 $f[0][0][0][0]=s_1$，其余为负无穷。每次选一种尚未用完的卡片，增加对应计数，再加新位置的分值。按四维下标递增处理；答案是 $f[c_1][c_2][c_3][c_4]$。

## 实现与复杂度

时间与空间均为 $O(\prod_{i=1}^4(c_i+1))$，每个状态最多四条转移。原题每类数量不超过 40。起点计分一次，终点也计分；不能只记录当前格子，因为相同位置的剩余卡片可能不同。

## 训练目标

先写状态和位置公式，再编码；重点理解“状态确定未来”，不背四维循环。
