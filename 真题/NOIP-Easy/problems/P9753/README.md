# 消消乐

2023 CSP-S · T2 · 提高 · 建议独立尝试 65 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/strings/README.md)

## 题意

一次可消除相邻的相同字符，统计能够全部消空的连续非空子串数。

## 关键部分分

- 小规模：枚举左右端点，对每个子串重新用栈消除，$O(n^3)$。
- 中等规模：固定左端点后向右延伸，复用当前栈，栈空就给答案加一，$O(n^2)$、空间 $O(n)$；这是一周训练优先实现的保底。
- 字母只有一种：偶数长度子串全部合法，枚举长度求和或直接按前缀奇偶计数，$O(n)$；有多种字母时不能只看每种字母出现次数是否为偶数，`abab` 就是反例。

## 做法

任何字符串反复消除相邻相同字符都有唯一约简串，可通过“当前字符等于栈顶则弹出，否则压入”得到。把每个前缀约简后的栈形态记为状态 $p_i$，空前缀为 $p_0$。

子串 $[l,r]$ 可消空当且仅当 $p_{l-1}=p_r$：消除规则等价于每个字符自逆的自由约简，两个前缀相同状态正好意味着中间串的约简为空。不能只比较栈深度。

用持久化 Trie 标识栈内容：结点记录父亲与最后一个字符，压入时沿“当前结点 + 字符”的孩子移动，不存在则创建；弹出时移动到父亲。每种栈内容对应唯一结点。

令 `cnt[root]=1`，每读入一个字符更新状态后，先 `ans+=cnt[p]`，再 `cnt[p]++`。

## 实现与复杂度

固定 26 字母的孩子数组实现时间 $O(26n)$（视常数即线性）、空间 $O(26n)$；需要核对内存，避免为 $n$ 个结点开过大的额外结构。用稀疏字典可降空间但增加常数。答案用 64 位。双哈希可替代 Trie，但有碰撞风险，训练优先精确状态法。

## 训练目标

先在 30 分钟内写完二次方栈模拟，再学习状态编号。必须能构造“计数偶数但不能消空”的反例。
