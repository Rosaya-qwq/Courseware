# 旅行

2018 NOIP 提高组 · Day 2 · T1 · 提高 · 建议独立尝试 60 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/graph/README.md)

## 题意

连通无向图满足 $m=n-1$ 或 $m=n$，从 1 开始进行 DFS，每点首次到达时记录编号，求字典序最小遍历序列。

## 做法

若是树，对每个点的邻居升序排序，按此顺序 DFS。进入较小儿子会在第一处差异得到更小编号，故局部顺序最优。

若 $m=n$，图恰有一个环。合法 DFS 的首次访问边构成生成树，等价于删掉环上一条边后遍历。枚举删边，运行升序 DFS；保留访问到全部 $n$ 点的序列，取字典序最小。可以枚举全部边并丢弃不连通者，或先删度数 1 的点定位环以减少枚举。

## 实现与复杂度

排序 $O(n\log n)$，枚举删边总时间 $O(n^2)$，空间 $O(n)$，原题 $n\le5000$。禁用的是无向边的两条邻接记录；不能只比较删边端点大小。深链注意递归栈。

## 训练目标

先完成树的分支，再加“枚举一条关键边”；本题 T1 也需要预留较长时间。
