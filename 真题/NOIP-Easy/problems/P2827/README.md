# 蚯蚓

2016 NOIP 提高组 · Day 2 · T2 · 提高 · 建议独立尝试 65 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/simulation/README.md)

## 题意

每秒取最长蚯蚓，切为 $\lfloor xu/v\rfloor$ 和剩余长度，其余蚯蚓增长 $q$。按题目间隔输出切前最长值与最终排名。

## 关键部分分

- 小规模：每次线性找最大、逐条增长，$O(m(n+m))$。
- 用最大堆和统一增量 `tag`：堆存 `实际长度-tag`，弹最大后计算两段，令 `tag+=q`，再把两段减去新 `tag` 入堆。时间 $O((n+m)\log(n+m))$，是可靠的中等规模保底；不能给刚切出的两段也增长 $q$。

## 做法

初始蚯蚓降序放入队列 $Q_0$，每次第一段放入 $Q_1$，第二段放入 $Q_2$；三个队列都存扣除全局增长后的值。每次只比较三个队首取得最大。

为什么新队列有序？设连续两次切前长度为 $x,y$，则 $y\le x+q$。两种切割函数 $f(x)=\lfloor xu/v\rfloor$ 与 $g(x)=x-f(x)$ 均单调，且 $f(x+q)-f(x)\le q$、$g(x+q)-g(x)\le q$。扣除相差 $q$ 的累计增长后，后产生的同类长度不超过前者，因此可用队列替代堆。

切割完成后固定 `tag=m*q`，继续三路归并输出最终排名，期间不再增加 `tag`。

## 实现与复杂度

时间 $O(n\log n+m)$，空间 $O(n+m)$。切割用整数乘除，乘积转 64 位；规范化长度可能为负。第一行每 $t$ 次输出，第二行从最终排名的第 $t$ 名重新开始计数，空行也要输出。

## 训练目标

先实现堆加偏移量，再证明三队列单调性。本周可以把堆做法作为保底目标。
