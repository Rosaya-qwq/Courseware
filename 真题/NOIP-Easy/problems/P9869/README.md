# 三值逻辑

2023 NOIP · T2 · 提高 · 建议独立尝试 75 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/graph/README.md)

## 题意

变量取 T、F、U，程序按顺序执行常量赋值、复制和取反，要求执行后各变量等于初值，最小化初值中 U 的个数；U 取反仍为 U。

## 关键部分分

- 小 $n$：枚举全部 $3^n$ 个初始赋值，模拟 $m$ 条语句，比较执行前后，时间 $O(3^n(n+m))$。应作为检验复杂解法的独立暴力。
- 只含 T/F/U 常量赋值：每个被写入变量只由最后一条赋值决定，统计最终被赋 U 的变量；未写入的变量可取 T/F，$O(n+m)$。
- 只含 U 和复制：先用符号模拟得到每点最终来源，建等式关系；与 U 在同一连通分量的变量必须为 U，其他分量可全取 T。并查集 $O((n+m)\alpha(n))$。这档不需要处理负号环，是优先练习的结构部分分。

## 做法

先**按程序执行顺序**做符号模拟。初始表达式 $e_i=X_i$；`+ x y` 时复制当前 $e_y$，`- x y` 时复制再取反，常量直接覆盖。这里复制的是表达式值，不是给两个会继续变化的变量永久连边。

程序结束，每个变量的固定点方程为 $X_i=e_i$，其中 $e_i$ 是常量或某个初始变量及一个取反位。

将 $X_i=\pm X_j$ 作为一条带奇偶权的无向边，权 0 表示相等，权 1 表示相反。逐连通分量 BFS，给每点相对根的奇偶颜色。

- 若有 U 常量约束，整个分量必须 U。
- 若发现奇偶矛盾（某个环的异或为 1），也必须全 U，因为只有 U 等于自己的取反。
- 否则若有 T/F 常量，检查其对根的取值要求并选定根；无常量则任选 T/F。该分量无需 U。

本题由复制/取反程序产生的每个方程分量至多通向一个常量，因此不会产生无法满足的相异 T/F 常量要求。实现仍可检查这一不变量以便定位符号模拟错误。

## 实现与复杂度

时间、空间 $O(n+m)$。常量 U 的取反不变；语句 `- x x` 必须先读旧表达式再取反。计数统计所有连入矛盾环的树枝，不能只统计环上的变量。

## 训练目标

本周完成枚举与“U + 复制”两档；再用带奇偶图遍历处理一般情况。
