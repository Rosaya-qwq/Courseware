# 括号树

2019 CSP-S · Day 1 · T2 · 提高 · 建议独立尝试 60 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/tree/README.md)

## 题意

树的点带括号字符。对每点 $u$，求根到 $u$ 的括号串中合法非空括号子串数 $ans_u$，最后输出 $\bigoplus_u u\cdot ans_u$。

## 关键部分分

- 小规模：为每点取出根路径串，对该串线性扫描统计合法子串，最坏 $O(n^2)$；可用线性括号串 DP，不需要枚举所有子串。
- 树是一条根链：直接在线性括号串上求 DP，$O(n)$。
- 全为左括号或全为右括号时答案为 0，只作边界分支；不能把只覆盖单色数据当成一般树算法。

## 做法

DFS 维护当前根路径上尚未匹配的左括号栈。令 $g_u$ 为以 $u$ 结尾的合法括号子串个数。若 $u$ 为右括号且栈非空，弹出匹配点 $p$，则

$$g_u=1+g_{fa_p};$$

其中 1 对应 $p\ldots u$ 整段，$g_{fa_p}$ 对应把此前的合法串接在其前面。否则 $g_u=0$。再令 $ans_u=ans_{fa_u}+g_u$，初始虚点 0 的两个值都为 0。

进入左括号点时压栈，回溯时弹出；进入右括号点时若弹出了 $p$，回溯时必须把 $p$ 恢复，确保兄弟分支互不影响。

## 实现与复杂度

时间、空间均为 $O(n)$。$ans_u$ 与 $u\cdot ans_u$ 用 64 位，先乘再异或；深链用显式进入/离开事件实现 DFS。栈空遇右括号不能把它当左括号压入。

## 训练目标

先在线性串实现 $g$ 递推，再加树的回溯恢复。
