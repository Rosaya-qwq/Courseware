# 货币系统

2018 NOIP 提高组 · Day 1 · T2 · 必练 · 建议独立尝试 45 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/dp/README.md)

## 题意

给出无限使用的币值，选尽可能少的币值，使能表示的非负金额集合完全不变。

## 关键部分分

- 极小 $n$：枚举保留币种集合，并用完全背包检查所有原币值能否表示，$O(2^n nV)$，只作小规模保底或对拍。
- 每次删去一种币值，重新做背包判断其是否能由其余币种组成，$O(n^2V)$。需要保留删币后的实际集合；更简单的提速是直接按从小到大处理。

## 做法

币值升序排序，布尔完全背包 `can[0]=true`。遇到 $a$，若 `can[a]` 为真则它由已保留的小币值表示，不必选；否则必须保留它，答案加一，并正序更新 `can[s]|=can[s-a]`。

未处理币值都不小于 $a$，不能帮助表示一个尚不可表示的更小正金额，所以当前必选决定不可避免。被跳过的币值已有等价表示，删去它不会减少可表示集合。

## 实现与复杂度

时间 $O(nV+n\log n)$，空间 $O(V)$，原题 $V\le25000,n\le100$。完全背包金额正序，多测清空数组；只判断整除关系不够，例如 $5=2+3$。

## 训练目标

45 分钟内通过；能证明必要币值必须保留，不能只把本题当背包模板。
