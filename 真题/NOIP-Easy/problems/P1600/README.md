# 天天爱跑步

2016 NOIP 提高组 · Day 1 · T2 · 拓展 · 建议独立尝试 80 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/tree/README.md)

## 题意

每个玩家从 $s$ 沿树上最短路跑到 $t$，经过一条边耗时一秒。点 $u$ 的观察时间为 $w_u$，求此时经过 $u$ 的玩家数。

## 关键部分分

- 小规模：预处理父亲和深度，逐条枚举 $s\to t$ 的路径并计算到达时间，$O(nm)$ 最坏上界。若用 LCA 可减少找路径开销，但仍需逐点访问。
- 全部 $w_u=0$：只统计起点出现次数，$O(n+m)$。
- 所有玩家起点均为根：只有 $w_u=dep_u$ 的点可能有贡献；在每个终点加一，求子树终点总数即可，$O(n+m)$。这是结构特例，若未核对对应原表，不标具体分值。

## 做法

将一条路径在 $p=LCA(s,t)$ 处分成上行 $s\to p$ 与下行 $p\to t$，下行不含 $p$，避免重复。根深度为 0。

上行点 $u$ 满足 $dep_s-dep_u=w_u$，即键值 $dep_s=dep_u+w_u$；下行满足 $dep_s+dep_u-2dep_p=w_u$，即键值 $dep_s-2dep_p=w_u-dep_u$。

对上行，在 $s$ 添加键 $dep_s$ 的 $+1$ 事件，在 $fa_p$ 添加 $-1$ 事件；对下行，在 $t$ 添加键 $dep_s-2dep_p$ 的 $+1$ 事件，在 $p$ 添加 $-1$ 事件。不存在的父亲忽略。

分别对两组事件做 DFS 桶统计：进入 $u$ 时记录查询键的桶值，递归全部儿子，再应用 $u$ 上的事件；用此时桶值减去进入时记录的值，就得到 $u$ 子树内事件净和。上下行结果相加即为答案。

## 正确性与实现

对路径 $s\to p$，某点子树内恰含起点而不含取消点，当且仅当该点在此祖先链上；下行同理。键值保证到达时间恰为 $w_u$。桶全局累加时一定用“离开减进入”的差值，防止混入兄弟子树。

LCA 时间 $O((n+m)\log n)$，事件统计 $O(n+m)$，空间 $O(n\log n+m)$。键值可能为负，可偏移或离散化；深链用显式栈。答案只计命中玩家，不是路径经过次数。

## 训练目标

本周优先保证逐路径暴力和 $w=0$ 特例；满分离线算法留作树上差分提高题。
