# 报数

2021 NOIP · T1 · 必练 · 建议独立尝试 40 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/math/README.md)

## 题意

若一个正整数含有数字 7 的因子，它就被禁止。给定 $x$，若被禁止输出 $-1$，否则输出比 $x$ 大的最小允许数。

## 做法

从小到大筛。若 $i$ 已被禁止可跳过；否则若其十进制含 7，就把它的所有倍数标记禁止。跳过已禁的含 7 数不影响结果，因为它的倍数早已被更小的含 7 因子覆盖。

筛完后从大到小维护最近允许数 `last`，先令 `next[i]=last`，再在 $i$ 允许时令 `last=i`。查询即可 $O(1)$ 回答。

## 实现与复杂度

上界 $U$ 必须超过最大询问并包含其后继；可用已知安全上界或扩大后验证最大询问确有后继。保守复杂度 $O(U\log U+T)$，空间 $O(U)$。原题询问可达 $10^7$，不要逐查询暴力找因子；检查自身含 7 不足以判断是否禁止。

## 训练目标

40 分钟内通过；筛完后验证后继覆盖范围，避免最大值附近越界。
