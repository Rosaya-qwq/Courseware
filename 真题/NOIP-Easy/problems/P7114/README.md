# 字符串匹配

2020 NOIP · T2 · 拓展 · 建议独立尝试 80 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/strings/README.md)

## 题意

统计 $S=(AB)^tC$ 的拆分，其中 $A,B,C$ 均非空、$t\ge1$，且 $A$ 中奇数次出现的字母种数不超过 $C$ 的对应种数。

## 关键部分分

- $|S|\le100$：枚举块长 $l=|AB|$、块数 $t$ 和切分点 $a=|A|$，直接或用预处理检查前缀周期，再用奇偶前缀状态比较 $F(A),F(C)$。字符串比较若逐字符进行，粗上界 $O(n^3\log n)$；先预处理每种周期可降为 $O(n^2\log n)$。
- $|S|\le1000$：对每个 $l$，预先记录各个 $a<l$ 的奇数字母数，建立 27 项前缀计数；周期检查使用下述 Z 函数，$O(n\log n+26n)$，实际上已可提升为完整算法。
- 只有一种字符：$F(A)=a\bmod2$，$F(C)=(n-tl)\bmod2$，直接枚举 $l,t$ 并计数合法奇偶切点，$O(n\log n)$，对应题面测试点 13～14。

## 做法

预处理每个前缀的奇数字母数 $pre[a]$ 和每个后缀的 $suf[b]$，奇偶用 26 位异或掩码维护；用 Z 函数得到 $Z[l]$，表示从位置 $l$ 开始与全串前缀的最长公共前缀（本段使用 0 下标）。

枚举块长 $l=2\ldots n-1$，把所有 $a=1\ldots l-1$ 按 $pre[a]$ 加入计数结构。块数 $t$ 合法当且仅当 $tl<n$ 且 $t=1$ 或 $Z[l]\ge(t-1)l$。对每个合法 $t$，求有多少切点满足 $pre[a]\le suf[tl]$，累加即可。

计数结构只需维护 0～26 的频数和前缀和；可用树状数组支持单次插入和前缀询问。注意每次 $l$ 增加只新增 $a=l-1$，不用重建。

## 实现与复杂度

枚举块长与倍数的总数为 $O(n\log n)$，配 27 大小树状数组，时间 $O(n\log n\log26)$，空间 $O(n)$。固定字母表可视为小常数。答案用 64 位；$C$ 非空对应严格 $tl<n$。不能只统计字符种类而忽略出现次数奇偶。
