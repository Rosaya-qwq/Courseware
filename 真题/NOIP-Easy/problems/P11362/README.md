# 遗失的赋值

2024 NOIP · T2 · 提高 · 建议独立尝试 75 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/math/README.md)

## 题意

长度为 $n$ 的序列 $x$ 取值 $1\ldots v$，给出若干单点限制 $x_c=d$。每条相邻限制形为 $x_i\ne a_i$ 或 $x_{i+1}=b_i$，即 $x_i=a_i$ 会强制下一位为 $b_i$。统计使全部限制可满足的二元组参数 $(a_i,b_i)$ 的选法，不是统计满足它们的 $x$ 的个数。

## 关键部分分

- $n,v$ 极小：枚举所有 $v^{2(n-1)}$ 组相邻参数，并枚举或 DP 判断是否存在合法 $x$；这是直接依据题意的保底，也适合作公式对拍。
- 只有一个固定位置：所有相邻参数都可满足，答案 $v^{2(n-1)}$，快速幂 $O(\log n)$。
- 相同位置被要求两个不同值：答案直接为 0；相同位置相同值只保留一次，不能当作长度为 0 的两端受限区间套公式。

## 做法

将固定位置排序、去重。两端相邻固定点之间没有其他固定点，设相距 $L$，其中有 $L$ 条相邻限制，共 $v^{2L}$ 种参数选择。

不合法当且仅当从左端固定值开始，每一步都触发强制赋值，最后强制成与右端固定值不同的数：第一条 $a$ 被左端固定，之后每个 $a$ 被前一条 $b$ 决定；前 $L-1$ 个 $b$ 任意，最后一个 $b$ 有 $v-1$ 种错误值。因此不合法数为 $v^{L-1}(v-1)$，合法数

$$f(L)=v^{2L}-v^L+v^{L-1}.$$

各区间参数独立，合法数相乘。最左固定点前和最右固定点后的边没有两端约束，每条边贡献 $v^2$，再乘 $v^{2(c_1-1+n-c_m)}$。无固定点时全部参数可行，单独返回 $v^{2(n-1)}$。

## 实现与复杂度

时间 $O(m\log m+m\log n)$，空间 $O(m)$，模 $10^9+7$。单点的具体值只影响重复位置是否冲突，正长度区间公式与两端值是否相同无关。指数和位置差用 64 位，减法规范到非负。

## 训练目标

本周先拿稳单固定点与冲突判断，重点理解“统计约束参数”与“统计变量赋值”两个不同对象。
