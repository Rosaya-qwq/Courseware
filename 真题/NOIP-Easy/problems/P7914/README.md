# 括号序列

2021 CSP-S · T2 · 拓展 · 建议独立尝试 90 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/dp/README.md)

## 题意

将 `?` 填为 `(`、`)` 或 `*`，统计符合超级括号序列文法的方案。连续星号段长度不超过 $k$；不能在最外层两端放星号，也不能在一层括号内同时放“星号 + 合法串 + 星号”。

## 关键部分分

- $n\le15$：枚举 $q$ 个问号的 $3^q$ 种替换，再做线性文法检查，$O(n3^q)$。检查时用栈分层，记录每层是否出现子括号块、块前后有无星号：`(SAS)` 禁止，而 `(S)`、`(SA)`、`(AS)` 可行；最外层禁止前后星号，任意星段长度不得超过 $k$。这覆盖测试点 1～3 的规模。
- $n\le40$：直接区间递推，即使辅助枚举多一层也可先用 $O(n^4)$ 的实现保底；下一步用辅助状态降为三次方。
- 全 `?`：仍可使用下面的区间 DP，不能仅按普通 Catalan 数计数，因为允许星号且有额外文法限制。

## 做法

定义 $S[l,r]$ 为该区间能否全填星号且长度在 $1\ldots k$；$P[l,r]$ 为整个区间由一对最外层括号包住的合法串；$A[l,r]$ 为一般合法串。另定义 $SA[l,r]$、$AS[l,r]$ 分别为“非空星号段 + 合法串”和“合法串 + 非空星号段”。

按区间长度递增。若 $s_l$ 可为左括号且 $s_r$ 可为右括号，则

$$P[l,r]=[r=l+1]+S[l+1,r-1]+A[l+1,r-1]+SA[l+1,r-1]+AS[l+1,r-1].$$

空区间的 $S,A,SA,AS$ 均取 0，所以长度 2 只贡献 `()`。按最后一个顶层括号块拆分，唯一地有

$$A[l,r]=P[l,r]+\sum_{t=l}^{r-1}(A[l,t]+AS[l,t])P[t+1,r].$$

再计算辅助状态：

$$SA[l,r]=\sum_t S[l,t]A[t+1,r],\quad AS[l,r]=\sum_t A[l,t]S[t+1,r].$$

两边区间均非空。先计算当前区间 $P,A$，再算 $SA,AS$，最终答案 $A[1,n]$。最后一个顶层块唯一，避免 `()()()` 被不同断点重复计数。

## 实现与复杂度

时间 $O(n^3)$，空间 $O(n^2)$，$n\le500$，模 $10^9+7$。初始化无效状态为 0，预处理 $S$ 可用“不可填星号的前缀个数”。空串不合法，`(*)` 合法，`(*()*)` 不合法，应列入自测。

## 训练目标

本周优先写枚举和文法检查；理解满分计数为何必须规定唯一拆分。
