# 排水系统

2020 NOIP · T1 · 提高 · 建议独立尝试 60 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/graph/README.md)

## 题意

有向无环排水图中，前 $m$ 个点各注入一单位水，每点把所有来水均分给出边，输出各汇点的最简分数。

## 做法

按拓扑序处理。每个点维护最简分数 $p/q$，前 $m$ 个点初值加 1，其余为 0。若出度为 $d>0$，将 $p/(qd)$ 加到每个后继；只有所有前驱都处理后才能分水。

分数相加先求分母的 gcd：$p_1/q_1+p_2/q_2=(p_1(q_2/g)+p_2(q_1/g))/(q_1(q_2/g))$，再约分。除以 $d$ 时可先约掉 $p$ 与 $d$ 的 gcd，减小中间值。

## 实现与复杂度

图遍历 $O(n+E)$，另计分数 gcd 的对数开销；空间 $O(n+E)$。中间乘加用 `__int128`，输出也支持该类型。拓扑队列由所有入度 0 的点初始化，而不是只放有水源的点；无水点仍影响入度。

## 训练目标

先完成分数加法、约分两个函数，再写拓扑；本题重点是精确运算，不能用浮点数猜分母。
