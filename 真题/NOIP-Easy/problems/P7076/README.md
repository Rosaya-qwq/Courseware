# 动物园

2020 CSP-S · T2 · 必练 · 建议独立尝试 40 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/math/README.md)

## 题意

现有 $n$ 种互异动物，编号为 $k$ 位二进制数。某位为 1 会要求指定饲料，求不增加饲料清单还能引入多少种新动物。

## 关键部分分

- $k\le20$：枚举全部 $2^k$ 个编号，检查会不会触发尚未购买的饲料，再减原有种类；$O(2^k m+n)$，对题面这一档足够。
- $k\le30$：已经推出自由位计数后，32/64 位可以直接算幂，先实现这一范围，再专门处理 $k=64$ 的边界。

## 做法

先将现有动物编号按位或为 $U$。原题保证所有规则的饲料编号 $q_j$ 互不相同，因此对每条规则，只要 $U$ 的第 $p_j$ 位为 0，该位就不能在新动物编号中置 1；否则该位所触发的饲料已经全买齐。

将这些禁止位去重，设有 $b$ 位被禁止，其余 $k-b$ 位任意，全部可养种类为 $2^{k-b}$，答案 $2^{k-b}-n$。

## 实现与复杂度

时间 $O(n+m+k)$，空间 $O(k)$。规则同位可重复，不能按规则条数减位数。读编号用无符号 64 位，计算答案用 `unsigned __int128`，以覆盖 $2^{64}$；不能执行 64 位类型左移 64。$n=0$、$m=0$、$k=0$ 均合法。

## 训练目标

40 分钟内通过；先用枚举验证自由位公式，再测试极限位宽。
