# 假期计划

2022 CSP-S · T1 · 提高 · 建议独立尝试 70 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/graph/README.md)

## 题意

从家出发依次游玩四个互异景点再回家，每一段至多转车 $k$ 次，最大化景点权值和。

## 做法

从每点 BFS，记录两点之间是否距离不超过 $k+1$；转车次数比边数少一，不能写成 $k$。枚举中间两点 $B,C$，要求它们互异且可达。

对每个 $B$，预处理同时满足 $1\to A$、$A\to B$ 可达的候选 $A$，只保留权值前三大。对 $C$ 同理得到候选 $D$。枚举两边至多 $3\times3$ 种组合，检查 $A,B,C,D$ 两两不同。

为什么前三个足够？固定另外三个点后，一侧候选本已排除自身及家，只可能被另一个中间点和另一端点这两个点占用；前三名中总有一个不冲突且不劣于排名更后的选择。

## 实现与复杂度

时间 $O(n(n+m)+n^2)$，空间 $O(n^2+m)$，原题 $n\le2500$。BFS 到深度 $k+1$ 可停止扩展。四个权值相加用 64 位，景点权值本身可达 $10^{18}$；候选数不足 3 时按实际数量枚举。

## 训练目标

较难 T1；先完成四点枚举的小规模程序，再学习“固定中间、两侧保留有限候选”。
