# 选择客栈

2011 NOIP 提高组 · Day 1 · T2 · 必练 · 建议独立尝试 40 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/prefix-binary/README.md)

## 题意

选两个同色客栈 $i<j$，要求闭区间 $[i,j]$ 中至少一个客栈的咖啡最低消费不超过 $p$，统计方案。

## 关键部分分

- $n\le100$：枚举左右端点并扫描区间找最低价，$O(n^3)$，覆盖原题 30% 范围。
- $n\le1000$：固定左端点，右端点递增时维护区间最低价，$O(n^2)$，覆盖原题 50% 范围。不要为每对端点重新扫描。

## 做法

正序扫描右端点 $j$，维护最近一个价格不超过 $p$ 的位置 $q$。合法左端点恰为 $i\le q$ 且 $i<j$、颜色与 $j$ 相同。

令 `cnt[c]` 统计已经纳入“可作左端点”范围的颜色数，指针 `t` 从不回退。每次先更新 $q$，再将 $t+1\ldots\min(q,j-1)$ 加入 `cnt`，最后令答案加 `cnt[color[j]]`。

## 实现与复杂度

每个位置被指针加入一次，时间 $O(n)$，空间 $O(n+k)$。答案用 64 位。若价格合格点就是 $j$，不能把 $j$ 自己作为左端点；若从未遇到合格点，贡献为零。

## 训练目标

独立写出二次方保底，再把“区间存在一个点”转为“左端点的上界”。
