# 寻找道路

2014 NOIP 提高组 · Day 2 · T2 · 必练 · 建议独立尝试 45 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/graph/README.md)

## 题意

有向图中寻找 $s$ 到 $t$ 的最短路，要求路径上每个点的所有出边终点都能够到达 $t$。

## 关键部分分

- $n\le10$ 或 $n\le100$：Floyd 求可达性，标记不合格点，再在允许点中 BFS，$O(n^3+m)$，覆盖原题 60% 范围。
- 不必枚举所有路径；即使只求部分分，也先把“所有出边终点可达”判断与最短路分开。

## 做法

在反图从 $t$ BFS，得到原图中能到 $t$ 的集合 $R$。根据**原图的这个固定集合**标记 `good[u]`：$u\in R$ 且 $u$ 的每个出边终点都属于 $R$。然后在只允许 `good` 点的原图中从 $s$ BFS，无法到达则输出 $-1$。

注意只标记一次：某个邻点本身不合格，不代表它不能到达 $t$。不能不断删除点并重新传播“坏点”，那会把题意加强。

## 实现与复杂度

时间 $O(n+m)$，空间 $O(n+m)$。反图只用于求可达，真正求路仍沿原图方向。先检查 $s$ 是否允许；距离不是拓扑层数，存在环也可 BFS。

## 训练目标

45 分钟内通过；能区分“能到终点”与“允许作为答案路径上的点”。
