# 火柴排队

2013 NOIP 提高组 · Day 1 · T2 · 必练 · 建议独立尝试 50 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/greedy/README.md)

## 题意

两列火柴各自高度互不相同，可交换相邻火柴。先最小化对应高度差的平方和，再求实现最小平方和所需的最少交换次数。

## 关键部分分

- $n\le1000$：先按下述排名配对，再用双重循环数逆序对，$O(n^2)$，覆盖原题 60% 范围。
- 极小规模可枚举排列检验配对性质；不建议把排列暴力作为 $n=10$ 的稳定实现。

## 做法

展开平方和，只需最大化对应乘积和。若 $a\le a'$ 且 $b\le b'$，同序配对比交叉配对多 $(a'-a)(b'-b)\ge0$，所以第 $k$ 小配第 $k$ 小。

记录两列每个排名的原位置。按第一列原顺序，将其映射为对应火柴在第二列的位置，得到一个排列。将两列同时看作同一组配对的两种顺序，任何相邻交换只改变一个配对相对次序，故最少交换数为该排列的逆序对数。

树状数组从左到右维护已出现的位置，当前贡献为 `已出现数量 - query(pos)`；也可归并排序计数。

## 实现与复杂度

时间 $O(n\log n)$，空间 $O(n)$。逆序对总数用 64 位，最后对 $99999997$ 取模；排名比较不需计算平方，避免高度平方溢出。

## 训练目标

先拿稳二次方保底，再把逆序对统计替换成树状数组。
