# 编辑字符串

2024 NOIP · T1 · 提高 · 建议独立尝试 65 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/greedy/README.md)

## 题意

两条 01 串各带一个掩码，掩码为 1 的相邻可动位置允许交换。分别重排可动字符，使两串对应位置相同的数量最大。

## 做法

把每串中掩码连续为 1 的位置合成一个可任意重排的块，掩码为 0 的位置各自是单独的固定块。统计每块剩余 0、1 数量。

从左向右处理位置 $i$，取两串当前位置所属块：若双方都有 0，就各取一个 0 配对；否则若双方都有 1，就各取一个 1 配对；否则双方剩余字符只能不同，各消耗一个但不加答案。

二进制条件下可以交换论证：若当前能匹配的字符在某个最优方案中放在后面，将它交换到当前位置；另一串同理。交换只影响当前位置和原来放该字符的位置，当前增加的一个匹配至少补偿至多一个被破坏的匹配，因此总能得到满足当前选择的最优方案。逐位固定即可。

## 实现与复杂度

时间、空间均为 $O(n)$。两串分块端点一般不同，不能简单对齐块；同为掩码 0 的连续段也**不能合为可重排块**。一个块的字符计数只在该块内消费，多测清空。

## 训练目标

先写分块与计数，再扫描配对。分别检查全固定、全自由、两侧分块交错的情况。
