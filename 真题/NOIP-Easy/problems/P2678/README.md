# 跳石头

2015 NOIP 提高组 · Day 2 · T1 · 必练 · 建议独立尝试 35 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/prefix-binary/README.md)

## 题意

从起点到终点之间移走至多 $M$ 块石头，使相邻保留位置的最小距离最大。

## 做法

二分最小距离 $d$。从起点向右扫描，若当前石头到上一块保留石头的距离小于 $d$，则移走当前石头，否则保留。把终点也作为最后一个待检查位置，统计需要移走的块数；终点不够远时，计数对应移走上一块保留石头，而不是实际删除终点。

保留最靠左且满足距离的位置，为后续留下的空间最多，所以该检查求得所需最少删除数。可行性随 $d$ 单调不增，取最大的可行值。

## 实现与复杂度

时间 $O(n\log L)$，空间 $O(n)$。若输入不保证有序先排序。终点必须参加检查，$M=0$、$M=n$ 都应自测；二分取上中位数以避免死循环。

## 训练目标

35 分钟内通过；能解释检查里的贪心，也能解释终点处的删除计数。
