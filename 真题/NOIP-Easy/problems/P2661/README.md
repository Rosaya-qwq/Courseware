# 信息传递

2015 NOIP 提高组 · Day 1 · T2 · 必练 · 建议独立尝试 40 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/graph/README.md)

## 题意

每个人恰好指向另一个人，消息沿有向边传递，求最短有向环长度。

## 关键部分分

- 小规模：从每个点独立沿后继走，用本次访问时间记录首次遇到重复点时的环长，$O(n^2)$。不要把重复点前的链长算进去。
- 改用本次搜索编号和全局访问标记，每点只遍历一次，也可直接达到线性；若不熟悉时间戳，推荐下面的删叶法。

## 做法

统计入度，把入度为 0 的点入队；不断删除该点唯一出边，并将新出现的入度 0 点入队。剩下的点恰好位于环上：非环点最终被剥离，环内每点始终至少有一个环内前驱。

在未访问的剩余点上沿后继走一圈，计数并更新最小值，标记该环全部点。

## 实现与复杂度

时间、空间均为 $O(n)$。本题是有向函数图，不能直接套无向图找环。每个环只计数一次；树枝上的点数不属于环长。

## 训练目标

40 分钟内通过；掌握“每点恰好一条出边 → 删入度零后只剩环”。
