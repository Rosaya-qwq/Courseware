# 划分

2019 CSP-S · Day 2 · T2 · 拓展 · 建议独立尝试 90 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/dp/README.md)

## 题意

把正整数序列划成若干连续段，段和不下降，最小化段和平方之和。

## 关键部分分

- $n\le10$：枚举 $n-1$ 个断点的子集，计算段和并检查不下降，$O(n2^{n-1})$，覆盖测试点 1～3。
- $n\le50$：$F[i][j]$ 为最后一段 $[j+1,i]$ 的最小总成本；枚举前段起点 $k$，仅当 $S_j-S_k\le S_i-S_j$ 时转移，$O(n^3)$，覆盖测试点 4～6，状态还可用于独立对拍。
- $n\le5000$：利用下述“最后段和最小”性质，枚举可行前驱求 $pre_i$，$O(n^2)$，覆盖测试点 1～16。这个性质本身需要证明，不能仅以“多分一段更优”代替。

## 做法

正数序列的最优划分可以取最后段和最小的一种；递归对前缀使用同样原则。证明需对两种划分的交替断点作交换，使后者的较大段向较小段转移总量，利用平方函数的凸性，详见所附证明。

令 $L_i$ 为最优前缀最后段和，$pre_i$ 为其前驱。选最大的 $j<i$ 满足

$$S_i\ge S_j+L_j,$$

则 $pre_i=j,L_i=S_i-S_j$。设阈值 $K_j=S_j+L_j$。新状态 $i$ 若满足 $K_i\le K_j$ 且 $i>j$，则它更容易可行且留下的最后段更短，状态 $j$ 被支配。

维护编号递增、$K$ 严格递增的单调队列：查询时，只要次队首满足 $K\le S_i$ 就弹队首，保留最后一个可行候选；计算新状态后，从队尾删除阈值不小于 $K_i$ 的候选，再插入 $i$。初始候选 0，$S_0=L_0=0$。

沿 $pre$ 从 $n$ 回溯，累加每段和的平方。

## 实现与复杂度

时间 $O(n)$，空间 $O(n)$，原题极限 $n=4\times10^7$。前缀和用 64 位；最终平方和用 `__int128` 并自行十进制输出。不要保存每个状态的大整数成本，只保存前驱。`type=1` 的生成器只是压缩输入，必须照题面公式读取并生成，不能忽略。

## 训练目标

本周目标为枚举断点与 $O(n^3)$ DP；掌握性质后再争取二次方档。极限线性实现作为拓展。
