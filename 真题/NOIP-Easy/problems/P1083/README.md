# 借教室

2012 NOIP 提高组 · Day 2 · T2 · 必练 · 建议独立尝试 45 分钟

[返回总目录](../../README.md) · [分类总结](../../categories/prefix-binary/README.md)

## 题意

每天有固定数量教室，第 $i$ 个订单在连续天数 $[s_i,t_i]$ 每天借 $d_i$ 间。按订单顺序执行，找第一个无法满足的订单。

## 关键部分分

- $n,m\le10^3$ 的训练规模：逐订单、逐天扣减，时间 $O(nm)$，最早出错时立即报告；是否覆盖原测试点以原题范围表为准。
- 用差分一次检查前 $k$ 个订单，$O(n+k)$；先把这个检查器写对，再加二分。

## 做法

`check(k)` 清空差分数组，对前 $k$ 个订单做 `diff[s]+=d, diff[t+1]-=d`，求前缀和得到每天占用，检查是否超过库存。因为 $d_i>0$，可满足性随 $k$ 单调不增。

若前 $m$ 个全部可满足，按题目格式输出 0；否则二分第一个 `check(k)==false` 的 $k$，输出 $-1$ 和订单编号。

## 实现与复杂度

时间 $O((n+m)\log m)$，空间 $O(n+m)$。需求总量用 64 位。每轮检查都重新清空差分，数组预留 $n+1$；失败订单编号不是失败的日期。

## 训练目标

45 分钟内通过，能独立完成差分检查和“第一个失败”的二分。
