# T2 部分分如何训练

[返回分类目录](README.md) · [七天安排](WEEK.md)

目录直接标出每道 T2 本周应完成的范围。单题“关键部分分”写清条件、方法、复杂度；有些解法覆盖原题已核对的测试点，有些是便于训练的限制算法。没有明确核对的限制不写保证分数，提交到某个 OJ 后的实得分也可能因补充数据或计分方式而不同。

## 一次训练的顺序

1. 先读题面，摘出总规模与特殊条件；题解先不展开。
2. 用 10～15 分钟写出可以确定正确的最简单算法，代入范围估算耗时。
3. 选择一个适用范围明确的保底实现，先通过样例，再造边界。
4. 留下可运行版本，再替换最慢的一层循环或增加特殊分支。
5. 复盘记录“适用条件、复杂度、还差哪一层”，不能只写一个总分。

不要把一个不完整的满分算法当作保底。保底应该是**在自己声明的数据条件内必然正确**，不是“随机数据可能过”。超出范围的分支若不正确，不能声称保证得分。

## 本周优先路线

| 类型 | 可执行路线 | 题目 |
| --- | --- | --- |
| 缩短统计时间 | 三次方 → 二次方 → 维护一个累计量 | 选择客栈、消消乐 |
| 先做判定器 | 逐次模拟 → 差分 → 二分首个失败 | 借教室 |
| 先数小规模 | 二次方逆序对 → 树状数组 | 火柴排队 |
| 按特殊参数减维 | 单段匹配、全单字符段 → 一般分段 DP | 子串 |
| 消去负号 | 常量分支、U/复制 → 带奇偶关系图 | 三值逻辑 |
| 固定局面不变量 | 两色一栈 + 辅助空栈 → 一般前瞻 | 喵了个喵 |
| 独立暴力求最优 | 枚举定价 + 背包 → 失败结构计数 | 清仓甩卖 |

## 合并多档时的注意事项

每个分支先检查条件，命中就运行对应正确算法。不同档可能重叠，不能把标称分数直接相加。题目可能一个测试文件含多个用例，某一用例不满足限制时不能把整文件按特殊情况处理。原题的编号参数可帮助识别数据类别，但应优先按实际限制编写能自检的分支。

若已有一般正确、只是在大数据上较慢的算法，它自然覆盖能在时限内跑完的小数据；不需要为“防超时”输出猜测答案。训练时同时记录正确性与实际运行规模。
