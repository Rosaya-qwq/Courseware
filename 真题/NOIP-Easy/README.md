# NOIP-Easy · T1/T2 分类训练目录

这份题单用于考前一周提高基础题的通过速度和稳定性。**T1/T2 是原比赛题号，并不表示所有题都简单。** 先按本页“本周训练目标”选正解或部分分，再进入单题文档；不要把完整收录理解为七天必须刷完全部题。

- [七天训练安排](WEEK.md)：每日必练、T2 保底与复盘要求。
- [一周速通题解课件](NOIP-Easy-Week.pdf)：按七天题序讲解 20 道主练题，附 2 道替换题、4 道选做题及对应部分分。
- [按年份核对完整题目](YEARS.md)：避免遗漏双日赛及同年两套赛事。
- [T2 部分分使用说明](PARTIALS.md)：怎样将限制解法变成稳定得分。
- [更新方法与单题模板](MAINTENANCE.md)：新增一个题目文件后自动刷新所有目录。
- [资料来源与核对说明](SOURCES.md)：题面、题解、分值与验证范围。

收录范围为 2010—2018 年 NOIP 提高组（2011—2018 年含两天各自的 T1/T2）、2019 年 CSP-S 两天各自的 T1/T2，以及 2020—2025 年 CSP-S 和 NOIP 两套赛事的 T1/T2。2019 年没有独立 NOIP 试卷，不虚构一套同年 NOIP。

**层次说明：**“必练”优先独立实现；“提高”按基础选做；“拓展”先完成目录指定的部分分。时间是独立思考与编码的上限建议，超过后看提示、实现保底并复盘，不是原卷时限或保证通过耗时。目录中的规模/特例只有在题解明确核对原计分表时才附原卷分数，其余只表示算法适用条件。

下面每类均有独立总结页；题目按训练层次和尝试时间排序。目录由单题元信息生成，更新时请修改单题文档。
